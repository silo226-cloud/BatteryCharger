# ⚡ מד טעינה (Charge Monitor) – אפליקציית אנדרואיד

אפליקציה צבעונית שמציגה בזמן אמת את כל נתוני הטעינה והסוללה.

## מה מוצג
| אזור | נתונים |
|---|---|
| טבעת סוללה | אחוז טעינה, מצב (בטעינה/פריקה/מלא), זמן עד טעינה מלאה, אנימציית "פעימה" בזמן טעינה |
| הספק נכנס | מד מהירות בוואט (מתח × זרם בפועל), דירוג מהירות (איטית / רגילה / מהירה / סופר / אולטרה), מתח, זרם רגעי וממוצע, מקור טעינה |
| מטען וכבל | ההספק המקסימלי שסוכם מול המטען (V × A), ניצול המטען באחוזים, הערכת איכות הכבל |
| סשן טעינה | זמן עד מלא, משך טעינה, אחוזים שנוספו, אנרגיה שנכנסה (Wh), הספק שיא, קצב % לדקה |
| גרפים | הספק וטמפרטורה ב־2 הדקות האחרונות |
| טמפרטורה | מעלות, מצב (קר/תקין/חמים/חם), פס צבעוני 20–50°C |
| בריאות סוללה | מצב מהמערכת, בריאות משוערת ב־%, קיבולת נוכחית מול מקורית (mAh), מחזורי טעינה (אנדרואיד 14+), סוג סוללה |

## 🔋 בדיקת פאוור בנק
מסך נפרד (כפתור במסך הראשי) שמודד כמה אנרגיה פאוור בנק באמת מעביר לטלפון:
1. מזינים את הקיבולת שעל המדבקה (mAh), מחברים ולוחצים "התחל בדיקה".
2. המדידה רצה ברקע (שירות עם התראה) גם כשהמסך כבוי, ונשמרת גם אם סוגרים את האפליקציה.
3. אם הטלפון מתמלא לפני שהפאוור בנק נגמר — מנתקים, משתמשים בטלפון, ומחברים שוב; הבדיקה ממשיכה לצבור.
4. כשהפאוור בנק מתרוקן לוחצים "הפאוור בנק התרוקן" ומקבלים: בריאות ב־%, קיבולת אמיתית משוערת, אנרגיה שנכנסה/יצאה (Wh) וכמה טעינות מלאות של הטלפון הוא נתן.

החישוב: פאוור בנק תקין מעביר לסוללת הטלפון כ־65% מהאנרגיה הרשומה עליו (mAh × 3.7V), בגלל הפסדי המרה וטעינה. הבריאות = נמדד ÷ צפוי. זו הערכה (±10%).

## מגבלות (חשוב לדעת)
- **סוג הכבל** לא נחשף ע"י אנדרואיד. האפליקציה מעריכה אותו לפי ההספק שהמטען והכבל סיכמו מול הטלפון לעומת מה שנכנס בפועל.
- **הספק המטען** נקרא משדות `max_charging_current/voltage` שקיימים ברוב המכשירים, אך לא בכולם.
- **בריאות משוערת** מחושבת ממונה המטען של הסוללה מול קיבולת היצרן — הערכה בלבד, ומשתנה בין יצרנים.
- מעל ~80% הטלפון מאט את הטעינה בכוונה, לכן ההספק יורד — זה תקין.
- iPhone לא מאפשר גישה לנתונים האלה, לכן האפליקציה לאנדרואיד בלבד.

## התקנה
כל push ל־`main` בונה APK ב־GitHub Actions ומפרסם אותו ב־Release בשם `latest`.
מורידים את `ChargeMonitor.apk` בטלפון ומתקינים.

## 🔄 עדכונים אוטומטיים
- האפליקציה בודקת כל 6 שעות (וגם בכל פתיחה) אם יש גרסה חדשה ב־Release `latest`, לפי הקובץ `version.json`.
- כשיש גרסה חדשה מגיעה **התראה** ("מד טעינה 1.X זמין"), ובמסך הראשי מופיע באנר "עדכן עכשיו".
- לחיצה מורידה את ה־APK ופותחת את מסך ההתקנה של אנדרואיד. בפעם הראשונה צריך לאשר לאפליקציה "התקנת אפליקציות לא מוכרות".
- מספר הגרסה נקבע אוטומטית לפי מספר הבנייה ב־GitHub Actions.

### מפתח חתימה (חובה)
עדכון מותקן מעל הגרסה הקודמת רק אם כל הגרסאות חתומות באותו מפתח. המפתח **לא** נמצא בריפו (הריפו ציבורי) — הוא שמור כ־Secrets:

| Secret | תוכן |
|---|---|
| `SIGNING_KEYSTORE_BASE64` | קובץ ה־keystore (PKCS12) בקידוד base64 |
| `SIGNING_STORE_PASSWORD` | הסיסמה שלו |

בלי שני ה־Secrets הבנייה נעצרת בכוונה, כדי לא לפרסם גרסה שלא תוכל להתעדכן.
